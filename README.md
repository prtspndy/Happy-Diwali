✨ About The Project

Happy Diwali is a small creative web project celebrating the spirit of India's festival of lights.

Designed with a festive aesthetic, the website brings Diwali celebrations to life through CSS illustrations, beautiful visual elements, and animated fireworks.

Whether you're celebrating with family, friends, or sharing festive wishes online, this project aims to deliver a simple yet delightful digital experience.

🌟 Features

- 🪔 Festive Design – A visually engaging Diwali-inspired interface.
- 🎆 Animated Fireworks – Canvas-powered fireworks for an immersive celebration.
- 📱 Responsive Layout – Designed to work across different screen sizes.
- ⚡ Lightweight & Fast – Minimal dependencies and optimized animations.
- ♿ Accessibility Friendly – Supports reduced-motion preferences and keyboard-accessible controls.
- 🎨 CSS Illustrations – Festive visuals created using CSS.
- 🔄 Replay Fireworks – Replay the celebration whenever you want.

💻 Getting Started

Want to explore or run this project locally?

Prerequisites

- A modern web browser
- Git installed on your system

Installation

1. Clone the repository

git clone https://github.com/prtspndy/Happy-Diwali.git

2. Navigate to the project directory

cd Happy-Diwali

3. Run the project

Open "index.html" directly in your browser.

That's it! You're ready to celebrate. 🎉

🌍 Deployment

This is a static website and can be deployed using:

- "Vercel" (https://vercel.com/)
- "GitHub Pages" (https://pages.github.com/)
- "Netlify" (https://www.netlify.com/)

Keep the project files together in the published directory.

♿ Accessibility & Performance

Performance and accessibility are important parts of this project.

- Fireworks respect the user's reduced-motion preference.
- Animations pause when the browser tab is hidden.
- Particle animations are capped to maintain performance.
- Decorative artwork is hidden from assistive technologies.
- Keyboard accessibility is supported for the replay control.
- System font fallbacks ensure usability if Google Fonts are unavailable.
